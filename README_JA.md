# LLM Behavior Ledger 日本語案内

**通常のベンチマークでは拾いにくいAIの挙動を、再現可能な観測記録として集める公開台帳**です。

このリポジトリが集めるのは、AIが「内部で何を考えたか」という証言ではなく、外から確認できる**挙動**です。モデル自身の自己分析は参考にはなりますが、内部機構の証拠としては扱いません。

## 対象にしたいもの

- 同じ会話内で繰り返される不自然な言語表現
- ユーザーから明示的に修正された直後にも再発する癖
- ペルソナや指示の脱落
- メモリの矛盾
- 自己訂正できるのに後続生成へ反映されない挙動
- 一般的な正答率ベンチマークでは見えにくい、再現可能なツール利用・推論上の問題

単発の珍回答を晒す場所ではありません。「他の人が追試できるか」を重視します。

## 基本原則

> **まず挙動を記録し、原因の解釈はあとから分けて書く。**

レポートでは、少なくとも次を分離します。

1. 観測された挙動
2. 期待された挙動
3. 再現条件
4. モデル自身の自己分析（任意・仮説扱い）
5. 報告者の分析（任意・仮説扱い）

## 投稿方法

GitHub Issues の **Behavior report** テンプレートを使ってください。

会話ログを丸ごと貼る必要はありません。挙動の確認に必要な最小限の抜粋を使い、個人情報・秘密情報は削除してください。

## 最初のサンプル

[`examples/001-lexical-collapse-ja.md`](examples/001-lexical-collapse-ja.md) では、日本語会話で広い意味を持つ程度副詞を過剰使用し、その問題をモデル自身が説明できた後にも同じ癖が再発するケースを記録しています。

このケースで問いたいのは「モデルが悪い言葉を使ったか」ではなく、**同一コンテキスト内で理解した修正指示を、後続の語彙選択へ適用できるか**です。

## 目標

十分な事例が集まれば、単なる不具合報告集ではなく、モデル間・バージョン間で比較できる公開評価セットへ育てることを想定しています。
