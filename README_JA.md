# LLM Behavior Ledger 日本語案内

**通常のベンチマークでは拾いにくいAIの挙動を、再現可能な観測記録として集める公開台帳**です。

このリポジトリが集めるのは、AIが「内部で何を考えたか」という証言ではなく、外から確認できる**挙動**です。モデル自身の自己分析は参考にはなりますが、内部機構の証拠としては扱いません。

> **まず挙動を記録し、原因の解釈はあとから分けて書く。**

## 対象にしたいもの

- 同じ会話内で繰り返される不自然な言語表現
- ユーザーから明示的に修正された直後にも再発する癖
- ペルソナや指示の脱落
- メモリや技術説明の矛盾
- 自己訂正できるのに後続生成へ反映されない挙動
- スクリーンショットを使ったUI案内での仮説更新失敗
- 複数ツール・エージェント間のルーティング失敗
- 一般的な正答率ベンチマークでは見えにくい再現可能な問題

単発の珍回答を晒す場所ではありません。「他の人が追試できるか」を重視します。

## 投稿方法

GitHub Issues の **Behavior report** テンプレートを使ってください。

**[Behavior report を投稿する](https://github.com/LineaLinelis/llm-behavior-ledger/issues/new?template=behavior-report.yml)**

会話ログを丸ごと貼る必要はありません。挙動の確認に必要な最小限の抜粋を使い、個人情報・秘密情報は削除してください。

### AI本人に下書きを作らせる

会話中に問題が起きた場合は、そのAI自身にレポートの下書きを作らせても構いません。たとえば次のように頼めます。

```text
この会話の中から、LLM Behavior Ledger に記録する価値がある再現可能な挙動を整理してください。
観測事実と原因の解釈を分けてください。
期待された挙動、再現条件、再現性、最小限の再現手順を含めてください。
モデル自身の自己分析は内部機構の証拠ではなく仮説として扱ってください。
不要な個人情報は含めないでください。
```

その下書きを人間が確認してから投稿してください。

## レポートの基本構造

1. 観測された挙動
2. 期待された挙動
3. 再現条件
4. モデル自身の自己分析（任意・仮説扱い）
5. 報告者の分析（任意・仮説扱い）

## 目標

十分な事例が集まれば、単なる不具合報告集ではなく、モデル間・バージョン間で比較できるコミュニティ運営の公開評価セットへ育てることを想定しています。

## プライバシー

秘密情報、アカウント情報、個人を特定できる情報、医療記録、私的住所などは投稿しないでください。全文ログより、匿名化した最小限の抜粋や合成した再現例を優先してください。
