# Contributing

Thanks for helping document model behavior.

## Before filing

- Try to reproduce the behavior at least once when practical.
- Search existing issues for similar reports.
- Remove personal or sensitive information.
- Keep direct conversation excerpts only as long as necessary to establish the behavior.

## Evidence vs interpretation

Please keep these separate.

**Evidence:**
- exact prompt or minimal reconstruction
- exact model output
- model/version shown by the product, if available
- language and interface
- date observed
- whether the behavior repeated

**Interpretation:**
- why you think it happened
- whether you suspect alignment, decoding, memory retrieval, language transfer, or another mechanism

Interpretation is welcome, but it must not be presented as an observed internal fact.

## Reproduction quality

A strong report answers: "Could another person try this without asking the original reporter what they meant?"

If yes, the report is probably ready.
